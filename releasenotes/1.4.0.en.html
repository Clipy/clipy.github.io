Clipy 1.4.0

Redesigned Settings and improved clipboard history management and snippet access.

Updating from a version earlier than 1.3.0 requires an internal database migration. Existing data will be migrated automatically where possible, but migration may fail depending on your environment.
Please export important data, such as snippets, before updating.

Enhancements

  • Redesigned Settings and added dark mode support.
  • Added a dedicated shortcut to open Settings even when the menu bar icon is hidden.
  • Added support for HTML format.
  • Added options to automatically clear history when Clipy quits or at a specified interval.
  • Added an option to exclude content received through Universal Clipboard from history.
  • Added a global shortcut to open the snippet editor.
  • Added an option to show snippets above history.
  • Automatically selected the first item when opening the menu to make keyboard navigation easier.
  • Improved menu title and number formatting.
  • Stopped saving text containing only whitespace or line breaks to history.
  • Reclaimed unused database space after manually clearing history.
  • Added Ukrainian localization.

Bug Fixes

  • Fixed pasting not working when the paste shortcut was changed in macOS settings.
  • Fixed screenshots not being captured in history when using a custom save location.
  • Fixed history pruning not following the current sort preferences when the history limit was exceeded.
  • Fixed problems when reordering snippet folders by dragging.
  • Fixed incorrect history submenu ranges when numbering starts at 0.
  • Fixed problems when adding snippets on macOS 13.

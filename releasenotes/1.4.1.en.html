Clipy 1.4.1

Improved menu interaction and display, and fixed bugs.

This is the last version of Clipy to support macOS 13 Ventura.

Updating from a version earlier than 1.3.0 requires an internal database migration. Existing data will be migrated automatically where possible, but migration may fail depending on your environment.
Please export important data, such as snippets, before updating.

Enhancements

  • Added an option to automatically select the first item when opening a menu with a shortcut.
  • Removed the (HTML) prefix from HTML history menu titles.
  • Added Persian localization.

Bug Fixes

  • Fixed being unable to select apps to exclude from clipboard history on macOS 13.
  • Fixed a problem where text could disappear when menu titles were long.

Release notes for 1.4.0
